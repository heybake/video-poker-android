# Video Poker Android

Standalone, offline Video Poker trainer and player for Android (Pixel 10 Pro / Pixel 10 Pro XL).

## Features
- **100% Offline & Self-Contained:** Plays anywhere without internet (airplane mode, travel, couch).
- **41 Built Games:** Imports all approved game JSON configurations from the Workbench.
- **3 Training Modes:**
  - **Learn:** Hold list shows the optimal moves and holds cards automatically.
  - **Practice:** Self-test mode comparing player holds against the optimal hold list.
  - **Casino:** Authentic casino simulation with full pay tables and zero hints.
- **Landscape Ergonomics:** Designed for one- and two-thumb play based on the collapsed single-column pay table and dedicated upper-right hold list real estate.
- **Local Session Recording:** Keeps full logs matching the Workbench format.
